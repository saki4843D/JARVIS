# JARVIS

A local-first Windows desktop assistant inspired by the calm, capable JARVIS
experience. It listens for a wake word, speaks answers, can use local Ollama
models for conversation and screen understanding, and performs a small set of
safe desktop actions.

## What it can do

- Text-only console for reliable testing.
- Local conversational AI through Ollama, with a short in-memory conversation.
- Open common Windows apps, Google, and YouTube; search Google safely.
- Tell time, battery status, and weather (when an OpenWeather key is supplied).
- Remember personal preferences in a local JSON file.
- Capture and describe the active screen, read visible text, or help interpret
  documents and code using OCR plus a local vision model.
- Optional webcam gesture control: open palm wakes JARVIS, fist sleeps, thumbs
   up confirms, thumbs down cancels, and a peace sign takes a screenshot.
- Lock the PC and take screenshots. Restart and shutdown always require a second,
  explicit spoken confirmation.

## Quick start

1. Install [Ollama](https://ollama.com/) and pull the local models:

   ```powershell
   ollama pull llama3.2
   ollama pull llama3.2-vision
   ```

2. In this folder, create and activate a virtual environment, then install the
   dependency list:

   ```powershell
   py -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

   Gesture control starts automatically when a webcam is available. If the
   camera or MediaPipe is unavailable, JARVIS continues in voice-only mode.

3. Copy `.env.example` to `.env`. Add `WEATHER_API_KEY` only if you want weather.
   Do not put credentials in source files.

4. Start the assistant:

   ```powershell
   .\.venv\Scripts\python.exe main.py  # reference-style fullscreen voice HUD
   python cli.py       # text console
   ```

   The reference HUD runs in its own Pygame thread while the voice listener,
   command router, and speaker continue in the assistant thread. Press `Esc`
   to close the HUD or say `exit` to stop JARVIS.

## Example commands

`help`, `open notepad`, `open youtube`, `search for a Python tutorial`,
`what time is it`, `battery status`, `weather in Bengaluru`,
`remember my favorite color is blue`, `what is my favorite color`,
`what is on my screen`, `take a screenshot`, `lock computer`, `system status`.

File and workflow commands include `list files`, `show files in Documents`,
`open file notes.txt`, and simple sequences such as `open Chrome and search for
Python tutorials`. Deleting a file always requires a separate `yes` or `cancel`.
Conversation history is retained locally in `memory/conversation.json`.

Mouse control is deliberately coordinate-based, so JARVIS only acts on a
specific place you name rather than guessing where to click. Move the mouse to
the top-left corner to trigger PyAutoGUI's emergency failsafe. Deleting data,
closing applications, installing software, spending money, sending messages,
and system power actions are not automated from a vague request; power actions
always require confirmation.

For power actions, say `shutdown computer` or `restart computer`, then say
`yes` only after JARVIS asks for confirmation. `cancel` dismisses a pending action.

## Configuration

All settings are optional environment variables in `.env`:

- `JARVIS_USER_NAME`, `JARVIS_ASSISTANT_NAME`
- `OLLAMA_URL` (defaults to `http://localhost:11434`)
- `JARVIS_CHAT_MODEL`, `JARVIS_VISION_MODEL`
- `JARVIS_DEFAULT_CITY`, `WEATHER_API_KEY`

## Tests

Run the offline routing checks with:

```powershell
pytest -q
```

The tests do not send requests to Ollama, use your microphone, or operate the PC.

## Design notes

Desktop controls are deterministic Python functions, not commands generated by
the language model. Vision and weather are optional integrations, so the core
text assistant remains usable while they are unavailable.
